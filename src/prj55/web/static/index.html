01 / NEURAL ARCHITECTURE

Spectro-Temporal Graph Attention (AASIST-L)

Rather than relying on uninterpretable million-parameter transformers, PRJ_55 implements the official AASIST-L architecture (Jung et al. 2022). Learnable SincNet filterbanks process raw audio waveforms directly, routing spectro-temporal nodes through heterogeneous graph attention layers to identify phase discontinuities, vocoder boundaries, and harmonic distortions.
